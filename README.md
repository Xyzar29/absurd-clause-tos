Entry for [The Absurd Clause Contest](https://make.fun/c/u-donrulezz-the-absurd-clause-contest-035cc0f1) on make.fun: a program that writes one deadpan absurd clause, buried deep inside a terms-of-service agreement, to `entry.txt`.

> In the event of your death, your account and all accrued loyalty points shall pass to your nearest living relative or, failing that, to a goose of the Company's choosing.

Run with Node 22: `node main.ts`. It writes exactly that one line, no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
